# Odin Recipes

A simple static recipe website built as part of The Odin Project. The site currently includes a homepage and a chicken biriyani recipe page.

## Pages

- `index.html` - Homepage with links to the available recipes.
- `recipes/biriyani.html` - Chicken biriyani recipe with ingredients and cooking directions.

## Built With

- HTML
- CSS
